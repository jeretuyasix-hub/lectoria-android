# Lectoria para Android

Lector EPUB en español con tutor contextual, memoria longitudinal de lectura, notas, estudio, hábitos y recordatorios.

## APK de prueba

El repositorio incluye un flujo automático de GitHub Actions llamado **Construir APK de Lectoria**. Cada cambio en `main` compila una versión Android de prueba y publica el artefacto `Lectoria-APK`.

> Esta es la versión funcional de prueba. El rediseño visual definitivo con Karl Marx como guía animado se incorporará después de validar la experiencia en la tableta.
